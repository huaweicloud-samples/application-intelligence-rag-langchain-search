# RAG 架构

## 架构图

```
┌─────────────────────────────────────────────────────────────────┐
│                        用户请求                                   │
└─────────────────────────────┬───────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    Python 脚本 (本地运行)                         │
│  - ask-huawei-with-rag.py (查询)                                │
│  - load-data-to-css.py (加载数据)                               │
└─────────────────────────────┬───────────────────────────────────┘
                              │
              ┌───────────────┴───────────────┐
              ▼                               ▼
┌─────────────────────────┐       ┌─────────────────────────────┐
│   ModelArts Studio     │       │    CSS (Cloud Search)      │
│   (LLM + Embeddings)   │       │    (向量数据库)             │
│                        │       │                             │
│ - 推理 API             │       │ - 向量索引                  │
│ - Embedding 端点       │       │ - 全文检索                 │
└─────────────────────────┘       └─────────────────────────────┘
```

## 组件说明

| 组件 | 说明 |
|------|------|
| ModelArts Studio | 华为云 AI 开发平台，提供 LLM 推理和文本嵌入能力 |
| CSS | 华为云云搜索服务，提供向量数据库能力 |
| Python 脚本 | RAG 应用核心逻辑，连接 ModelArts 和 CSS |

## 部署方式

1. **CSS 集群**: 使用 Terraform 创建
2. **模型推理**: 通过 ModelArts Studio API
3. **Python 脚本**: 本地运行，连接华为云 API
